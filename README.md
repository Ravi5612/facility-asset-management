# Facility Asset Management System

A comprehensive, enterprise-grade Asset & Visitor Management System built for modern organizations.

## Features
- Role-Based Access Control (Super Admin, Sub-Admin, Security, Employee)
- Asset Management & Assignment
- Helpdesk Ticketing System (Issue, Repair, Replacement)
- Visitor Management System (Gatepass)
- Complete Audit History & Logs

## Tech Stack
- **Frontend:** Next.js 14 (TypeScript)
- **Backend:** NestJS (TypeScript)
- **Database:** PostgreSQL + Prisma ORM
- **Styling:** Tailwind CSS + shadcn/ui
- **Auth:** NestJS Passport + JWT
